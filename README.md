# 🌐 Company Website – RQA Supplies

## 📖 Overview
This repository contains the source code for the official **RQA Supplies** company website.  
The site is designed to showcase our products, services, and contact information in a modern, responsive format.

---

## 🚀 Features
- Responsive design optimized for desktop and mobile  
- Company overview and mission statement  
- Product/service listings  
- Contact form with backend integration (Netlify Forms or third‑party service)  
- SEO‑friendly structure and metadata  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (or React/Next.js if applicable)  
- **Styling:** Tailwind CSS / ShadCN UI  
- **Deployment:** Netlify / Vercel  
- **Version Control:** Git + GitHub
